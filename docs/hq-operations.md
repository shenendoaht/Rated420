# Rated420 HQ operations

This sandbox refinement starts from `49dad9b7e2178893236810d3029d02dde8d954a8`. The preserved rollback deployment is `dpl_CG3jS7kQt77MWCU1wUzQKmXPVy9H`.

## Use the desk

- **Rated420 HQ** starts at Needs attention. Open a pending submission and record a decision in place. Use View all submissions for the complete queue. Founder and administrator roles also see open tasks and catalogue review activity.
- **Founder workspace** opens on follow-ups, correspondence, open opportunities, scheduled production, intake and recent changes. Open a record directly and use the named Back control to return to the previous view and filters. The menu organizes the existing records under Today, Business, Intelligence and Operations.
- **Territory Explorer** offers named keyboard-operable region controls and a schematic map. An official license count and classification breakdown sit beside the regional selector. Synthetic business cards and metrics remain in a separate queue. Open CRM or prospect records, then use Back to Territory Explorer to return to the selected region and record filters in the same browser tab.
- **Data Intelligence Center** shows snapshot retrieval, applied local batches and skipped or rejected rows. Open each source's Provenance and controls disclosure for the version, conditions and local diagnostics. The available licensing data is a bundled NYS snapshot. Third-party providers require separate authorization and use only simulated or manual workflows here.

The dashboard and navigation reuse current records and permissions. Existing review, moderation, catalogue, correspondence, production, finance and task operations still use the original local adapters. Region and directory view preferences are scoped to the browser tab and demo actor. No provider or production service is contacted.

## Visual hierarchy

Primary actions use the existing light purple-to-green gradient. Secondary actions have an outlined surface. Tertiary actions are text-forward. Selected navigation retains ARIA state and an inset visual indicator. Destructive catalogue and local record controls use the warning palette and ask for confirmation. The homepage membership section now lets its background theme supply the supporting-copy color through a shared CSS variable. Its primary text uses Pearl over the existing gradient. The catalogue cards retain their specific grid, balanced title and description type, and shorter cards.

## Open the offline package

Extract the ZIP. Open **Launch Rated420.command** on macOS or run `/usr/bin/perl ./serve-rated420.pl` in the extracted directory and open `http://127.0.0.1:8768/`. See README.md for demo accounts and VISUAL-SYSTEM.md for shared tokens. The visual comparisons and verification notes accompany the package.

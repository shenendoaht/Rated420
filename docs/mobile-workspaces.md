Use the same Menu control, Escape, or a pointer outside the menu to close it. Destination activation closes the menu. The mobile development toolbar retains the sandbox label and expands to expose the existing role and reset controls. Desktop presentation retains the separate hosted sandbox banner.

HQ prioritizes outstanding submissions and places recent activity behind a disclosure. Founder removes repeated counts and reveals simulated settings on demand. Pending approvals or intake move ahead of routine queues when action is required. The original role boundaries and record return paths continue to apply.

Territory lists the number of state-reported license locations represented by each schematic region. Choose a region with the map or a named keyboard-operable row. Selection updates the official breakdown, local prospect context and separate simulated business list. The state counts follow the bundled snapshot, with records lacking a mapped region represented only in the applicable all-regions view. A count measures license locations and does not establish market activity.
